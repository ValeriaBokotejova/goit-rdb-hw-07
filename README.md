# goit-rdb-hw-07

## 📘 Date and Time SQL Queries

This project contains SQL queries working with date and time functions in MySQL, using the `orders` table.

### ✅ Tasks Covered

1. Extract year, month, and day from the `date` column and display them alongside `id` and the original `date`.
2. Add one day to the `date` and display the result with `id` and original `date`.
3. Convert the `date` to a Unix timestamp in seconds.
4. Count how many rows have a `date` between `'1996-07-10'` and `'1996-10-08'`.
5. Generate a JSON object from each row with keys `id` and `date`.

Each query was tested and executed in MySQL Workbench.
